To publish the changes on GitHub:

  1. Open the website repository on GitHub.
  2. Click Add file, then Upload files, and drop the new content.js. It replaces the old one.
  3. New photos or logos go in the speakers/, people/ or logos/ folders, uploaded the same way.
  4. Click Commit changes. The site updates within a minute or two.
